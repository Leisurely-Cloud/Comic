# 最近压缩包阅读记录验收

日期：2026-10-22 起实施。沿用当前未提交工作区，保留此前的书库、阅读器、批量导入与 CBZ / ZIP 阅读改动，没有提交或发布。

## 使用入口

“我的书库 → 打开 CBZ / ZIP”主按钮继续选择文件；右侧箭头显示最近 5 个成功阅读的压缩包，点击后按原章节、页码及阅读偏好继续阅读。“管理最近记录”显示最多 20 条记录，包含文件标题、完整路径和上次页码，可移除所选或清空记录。

只有分页 / 双页成功完成图片解码，或条漫可视图片完成加载后才记录。章节索引、缩略图和图片预读不算成功阅读；取消、迟到回调、解码失败和无效归档不新增记录。每个阅读会话只记录一次，重新打开同一路径后更新排序，不重复占位。

记录保存在应用数据目录的 `recent-archives.json`，采用原子写入及上一份备份；移除或清空失败时保留原列表并提示。自动记录失败不阻碍当前阅读。

## 数据与授权边界

- 列表只读取历史元数据，不探测归档是否存在，不扫描外部磁盘；用户主动点击后重新校验文件并建立新的归档会话。
- 文件丢失或移动时保留历史，在打开时显示原有“无法读取压缩包”提示。移回原路径后可继续原进度；不自动查找或迁移文件。
- 移除历史保留源文件、阅读进度、阅读状态、偏好和书签。历史不加入目录书库或分类计数。
- 最近记录纳入现有备份、恢复和损坏修复。旧备份没有该文件时保留现有历史；备份只含记录，不含源归档内容。
