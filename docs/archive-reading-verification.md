## 使用入口与行为

“我的书库 → 打开 CBZ / ZIP”选择本地压缩包后进入现有阅读器。根目录图片为“根目录”章，嵌套目录使用完整相对路径分章，章节和图片按数字自然排序。单页、双页、条漫、页码缩略图、进度、阅读偏好及书签备注共用现有实现。

每次仅读取所需图片，不解压到磁盘，不修改源压缩包。外部归档只在明确选择后授权；图片使用随机会话令牌，离开阅读器或取消加载时撤销授权。普通本地图片仍遵守原有书库访问边界。

## 当前范围

- 支持普通、未加密、非分卷 ZIP / CBZ，暂不支持 RAR / 7z。
- 默认上限：8 GiB 文件、50000 个条目、64 MiB 中央目录、64 MiB 单图、16 GiB 图片总大小。
- 进度、书签、偏好以完整文件路径为标识；手动移动文件不自动迁移记录，修改或替换归档后须重新打开。
- 直接打开归档不会自动加入书库列表、书架标签或分类计数。
- 加载取消、过期回调和资源上限由自动化回归验证；没有用真实大型漫画库进行压力测试。
